# 失败分类与修复边界

自修是“观察差异→定位层级→保留原件→窄范围修正→相关测试→真实复验”的闭环，不是无限重试。

| 差异 | 先看 | 修复与复验 |
|---|---|---|
| 源样式文字露出 | 完整DOM、未闭合空footer、迁移追加样式位置 | 只调整迁移自己追加的段，分块读长源码、保存后全长和哈希对账；不得启用来源原本无效的尾部脚本 |
| 美化变暗/按钮异色 | 作者CSS与宿主颜色、透明背景、控件语义映射 | 独立组件不继承平台基调；同族原生控件继承原按钮风格；不把播放器皮肤变平台默认按钮 |
| 状态栏变形/小火丢失 | 来源皮肤、flex尺寸、fixed归属、流式所有者 | 保留真实侧边定位和最新完整消息生命周期；既有折叠保持；不同真实scrollTop核对坐标 |
| 独立播放器被挤窄 | 子元素计算boxSizing、作者padding与外宽 | `repair --job ... --worker ... --rank ... --input relative-public.html` 仅支持识别censy-player-shard后收窄迁移所有的mobile-box-model universal reset；输出单独proposal与前后哈希，不覆盖来源，必须真实复验 |
| mufyer未绑定 | 来源文本节点、玩家/面具context、重复srcdoc | 仅展示文本模板绑定；不改署名/属性/代码；更名时保留节点与展开状态 |
| 复制成功但没效果 | 指令文本、草稿、selection/caret、实际粘贴 | 不能相信COPIED或execCommand返回true；用不同已知文本验证真实效果，不读取无关剪贴板内容。当前HTTP复制缺陷未通过，勿混入已验补丁 |
| 外部媒体失败 | 原始URL、自然尺寸/时长、当前进度、实际错误 | 每项有界尝试并记录；源站也失败不能虚构target通过；不替换资产、不绕网络/沙箱限制 |
| 同名角色/版本差异 | 多项人物事实、关系、经历、世界观与授权本地哈希 | 保留明确对应/差异/冲突；不能仅凭名称或热度通过 |

其他变化由 Codex 编写实际兼容修复，但必须在单独分支/提案目录保存，注明适用组件族和反例，测试普通卡/无美化卡未被误伤。不能把某一角色的类名替换经验无条件套到所有卡。

平台公共文件（ChatRoom、RegexIframe、iframe-bridge、共享颜色/工具栏）由协调者统一修改与发布。执行者遇到公共缺陷先交最小复现、文件、前后截图、测试和提案，不直接抢改共享测试服。源码快照是参考，不是批准部署；runtime-candidate 标记未发布时仍然未发布。

修复后只重查受影响项及必要负向回归，合并/发布后绑定新runtime指纹复验；没有相关变化不重跑既有成功26条指令或298个框来堆数量。没有授权、来源不可用、工具服务无法观察的项写 blocked/pending 并继续其他卡；不能为完成报告而删掉验收条件。
