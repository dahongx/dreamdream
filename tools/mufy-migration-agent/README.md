# Mufy迁移 Agent 交接包

第一次使用先读 [中文使用说明](references/使用说明.md)，它区分协调者和执行者，并给出从收到包到交回结果的步骤。

当前状态：1.0.1-rc.2 候选，尚未通过真实单卡全链路验收，禁止用于多人批量迁移。1.0.0 已撤回批量使用推荐：它遗漏了原批次准备脚本的额外兼容步骤；基础核心相同不等于实际完整链路相同。工具测试和文件哈希不能代替真实样本验收。

给执行者的启动话术：

> 使用本目录的 `$mufy-migration-agent`。先运行 doctor，读取协调者提供的 job 和 assignment，仅处理分配给你的卡。通过正常来源页、授权本地档案和8091正常网页导入，自查差异、自修并实际复验；完成全部分配项后交回逐卡报告及证据，不以导入成功或局部测试通过代替验收。共享渲染器变更交协调者统一处理。

这是一版可复用 Codex 技能与本地工具，不是后台无人值守的一键搬运服务。浏览器交互、语义和视觉审阅由有工具权限的 Codex 执行；确定性的版本/分工/准备/完整性检查交 CLI。只有一个已证明的自动盒模型修复配方；其他差异由 Codex 定位修改并复验，不承诺任意作者脚本零人工返修。

先运行 `bun dist/agent.mjs doctor`，所有命令只需要 Bun，转换核心和运行依赖已内嵌；具体命令、分工和证据格式见 references/operator.md。安装为技能时复制整个包至 `~/.codex/skills/mufy-migration-agent/`，不要只复制SKILL.md。已有同名技能先核对版本，不覆盖正在执行的版本。也可以直接把本目录和上述启动话术给另一位Codex，不必改本机配置。

release.json 是本包身份：记录原始仓库基准、每个实际冻结文件SHA256和 packageId。reference-source 是转换核心依赖及工作流源码参考，不是整站可部署副本；runtime-candidate 是另行准备的11文件未发布提案，与现有测试服运行代码不同，不得整目录直接覆盖服务器。任何改包后 doctor 必须失败，需由协调者重建新版本并重新分配。

本包不含 token/cookie/环境文件、数据库内容、真实人物Prompt原文、原始角色大档案、浏览器登录或真实聊天证据。不要发送整个原工作目录。个人原始档案和准备XML只在对应授权job内使用。工具不含旧凭据采集器、旧直接写库入口或发布命令。

依赖和使用浏览器工具的可用性由执行者环境提供。Bun版本、打包校验、正负向测试与离线端到端结果见 VALIDATION.json；这些是工具包验证，不代表原有30张卡已经验收完成。
