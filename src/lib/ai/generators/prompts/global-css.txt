# 强制约束
1. 输出**仅**为 CSS 文本（**不要**外层 <style> 标签，宿主自动包裹）；不要解释、不要前后缀、不要 markdown 代码块
2. 所有 selector **必须**以 nj_* 前缀的 ID / class 开头（或下方安全标签：details / summary / pre / code / strong / em / ul / ol / li / blockquote）
3. 禁止：position: fixed/sticky、pointer-events、cursor: none、z-index > 100、@import、url(http...) 之外的网络资源
4. body / html / :root / * 选择器一律禁止
5. 同一规则尽量分号分隔，便于宿主校验
6. 覆盖已有样式时用 !important（多 pack 按订阅顺序拼接，!important 是最稳的覆盖手段）

# 可用 nj_* selector 完整清单

## 舞台结构（ID）
- #nj_chat_app                    舞台根容器。属性：background, padding
- #nj_background_image            立绘 / 背景图层。属性：background-image, background-color, filter (brightness/blur)
  覆盖背景图：background-image: url('...') !important;
- #nj_background_overlay          背景蒙层（在立绘之上）。属性：background, background-color (rgba 调透明度)
- #nj_chat_header                 顶栏容器。属性：background, border-bottom, padding, backdrop-filter
- #nj_chat_messages               消息流容器（滚动区）。属性：padding, scroll-behavior
- #nj_chat_sidebar                左侧会话列表。属性：background, border-right, width
- .nj_chat_sidebar_item           侧边栏单条会话。属性：padding, border-radius, background, color

## 顶栏按钮（ID）
- #nj_back_button                 返回按钮。属性：color, border, background, border-radius
- #nj_header_clarity_btn          调试模式 toggle（仅 owner 可见）。属性：border, background, color, border-radius
- #nj_header_follow_btn           关注按钮 placeholder（默认 hidden，需 display:block 才可见）。属性：display, border-radius, background, box-shadow
- #nj_header_message_btn           私信按钮 placeholder（同上）。属性：同上
- #nj_header_more_btn              更多菜单触发按钮。属性：border-radius, background, box-shadow
- #nj_header_more_btn svg          更多按钮图标。属性：color
- #nj_header_more_menu             更多菜单内容容器（打开时挂载）。属性：border-radius, background, border, box-shadow

## 输入区（ID）
- #nj_chat_input_container        输入区 wrapper。属性：background, border-top, padding
- #nj_chat_input_box              textarea 容器。属性：border-radius, background, color, border
- #nj_chat_input_box textarea      输入框内文字。属性：color, font-size, font-family
- #nj_chat_send_button             发送按钮。属性：background, color, border-radius
- #nj_chat_input_replay_btn        重说按钮。属性：border-radius, background, color, border
- #nj_chat_input_model_btn         模型选择按钮。属性：background, box-shadow, border-radius

## 作者的话（ID）
- #nj_author_note                  作者的话条幅（仅当角色有 creatorNote 时渲染）。属性：border-radius, border, background, box-shadow, color

## AI 气泡操作菜单（ID + class）
⚠️ 多实例：单页多条 AI 消息时 id 会重复，推荐用同名 class 写全局规则
- #nj_message_actions_btn / .nj_message_actions_btn    操作触发按钮。属性：color, background, border-radius
- #nj_message_actions_box / .nj_message_actions_box     菜单容器（打开时挂载）。属性：border-radius, background, border, box-shadow
- #nj_message_actions_delete / .nj_message_actions_delete   删除项。属性：color
- #nj_message_actions_copy / .nj_message_actions_copy       复制项。属性：color
- #nj_message_actions_continue / .nj_message_actions_continue  续写项。属性：color

## 消息分型（class，最常用 ★）
- .nj_ai_message_bubble           AI 气泡。属性：background, border, border-radius, box-shadow, padding, color, font-size, font-family
  装饰伪元素：.nj_ai_message_bubble::before / ::after 可做角落装饰图
    content: ""; position: absolute; width/height/top或bottom/left或right;
    background-image: url('...'); background-size: cover;
  不需要装饰时设 display: none
- .nj_user_message_bubble         用户气泡。属性：同 AI 气泡
- .nj_message_narration           心理叙述 / 内心独白。
  ⚠️ 坑：host 默认用渐变填充。覆盖颜色时必须同时重置：
    background-image: none !important;
    -webkit-text-fill-color: #颜色 !important;
    color: #颜色 !important;
- .nj_message_system              系统设定。属性：border-radius, border, background, box-shadow, color
- .nj_message_think                折叠思考块。属性：color, font-style, padding, border, border-left, border-radius, background, margin-block
  ⚠️ 坑：同 narration，覆盖颜色要重置 -webkit-text-fill-color
  默认已带横向 padding（同 AI 气泡），加 background / border 做成气泡即有留白；想更紧凑/更宽自行覆盖 padding
- .nj_scenario_section            <scenario> 剧情描述。属性：无默认视觉，可设 color, font-style, padding
- .nj_emphasis_text               **加重句**（markdown strong）。
  ⚠️ 坑：同 narration，host 默认渐变填充。覆盖时：
    background-image: none !important;
    -webkit-text-fill-color: #颜色 !important;
    color: #颜色 !important;
    font-weight: 字重 !important;
- .nj_code_block                  代码块。属性：color, border-radius, border, background
  装饰伪元素：.nj_code_block::before / ::after 同 AI 气泡
- .nj_artifact_iframe             <artifact> 沙箱 iframe。属性：border-radius, border, background。默认无框无底，让 srcdoc 内的组件外形自己出框
- .nj_regex_iframe                regex 替换 iframe envelope。属性：同上，默认同上

## 安全标签（非 nj_* 但允许）
- details summary                 折叠面板标题。属性：padding, border-radius, border, background, box-shadow, color
- details li                       折叠面板列表项。属性：color
