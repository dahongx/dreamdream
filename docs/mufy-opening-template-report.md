## 二、两大通用模板

### 【模板 A：cen-sub-panel 类型】（31 张卡使用）

**视觉特征**：
- 右下角浮动圆球（可拖拽）
- 点击圆球展开折叠面板
- 面板包含 ▲▼ 上下滚动按钮
- 适合信息密集型展示

**HTML 结构**：
```html
<div id="cen-nav-wrapper">
    <div class="cen-sub-panel" id="cen-sub-panel">
        <div class="cen-action-btn" onclick="parent.Tuan_init_up(event)">▲</div>
        <div class="cen-action-btn" onclick="parent.Tuan_init_down(event)">▼</div>
        <!-- 更多内容面板 -->
    </div>
    <div class="cen-ball-main" id="cen-ball-main" 
         onmousedown="parent.cold_drag_start(event)" 
         ontouchstart="parent.cold_drag_start(event)" 
         onclick="if(!parent.cen_isDragging) parent.Z_CONFIG_toggle()">
        ◆
    </div>
</div>
```

**JavaScript 功能**：
- `Z_CONFIG_toggle()`：切换面板显示/隐藏
- `Tuan_init_up()`：滚动到页面顶部
- `Tuan_init_down()`：滚动到页面底部
- `cold_drag_start()`：拖拽浮球

**使用角色**（31 张）：
- 陆予觉
- 许霖
- 谢澄
- 潘其光
- 永济一中4＋1
- 简凡
- 方越
- 谢泽
- 陈昌庭
- 宋淞
- ...

**适合场景**：
- 复杂关系网
- 多线剧情
- 需要大量信息展示
- 律政/商战/权谋题材

### 【模板 B：top-adaptive-dock 类型】（24 张卡使用）

**视觉特征**：
- 顶部灵动岛（类似 iPhone Dynamic Island）
- 点击展开显示信息卡片
- 音乐播放器风格
- 现代感强，视觉冲击力高

**HTML 结构**：
```html
<div class="top-adaptive-dock">
    <div class="my-unique-island-wrapper">
        <div class="island-container">
            <!-- 收起状态：小黑条 -->
            <div class="island-mini">160px × 35px</div>
            
            <!-- 展开状态：信息卡片 -->
            <div class="island-expanded">
                <!-- 人物信息、音乐控件、互动元素等 -->
            </div>
        </div>
    </div>
</div>
```

**CSS 特征**：
```css
.top-adaptive-dock {
    position: fixed;
    top: 10%;
    left: 50%;
    transform: translateX(-50%);
    z-index: 9999;
    width: 300px;
}

.island-container {
    width: 160px; 
    height: 35px;
    background: rgba(15, 15, 15, 0.1); 
    border-radius: 40px;
    transition: all 0.7s cubic-bezier(0.19, 1, 0.22, 1);
}

.island-expanded {
    width: 350px;
    height: auto;
    /* 展开动画 */
}
```

**适合场景**：

- 强视觉冲击

## 三、两大模板对比

| 维度 | cen-sub-panel（A） | top-adaptive-dock（B） |
|------|-------------------|----------------------|
| **位置** | 右下角浮球 | 顶部居中 |
| **交互** | 点击展开折叠面板 | 点击展开灵动岛 |
| **视觉风格** | 实用型、信息密集 | 现代感、视觉冲击 |
| **内容容量** | 大（可滚动面板） | 中（固定展开尺寸） |
| **使用数量** | 31 张（34%） | 24 张（26%） |
| **代表角色** | 陆予觉、许霖 | 祁叙、谢寻 |
| **适合题材** | 律政/商战/复杂剧情 | 成人向/现代都市 |

## 六、模板的复用方式

### Mufy 的做法

1. **设计一套通用模板**（如 cen-sub-panel）
2. **定义占位符区域**：
   - 浮球图标：可替换
   - 面板内容：可定制
   - 颜色主题：可调整
3. **为每个角色填充内容**：
   - 复用 HTML/CSS 结构
   - 只改变内容和配色
   - 保持交互逻辑一致

### 我们可以怎么做

#### 方案 1：直接复用 Mufy 模板（最快）

**黎衡**：
1. 复制祁叙的 top-adaptive-dock 完整代码
2. 替换内容：
   - 祁叙的"好感度" → 黎衡的"关系温度"
   - 祁叙的"群聊" → 黎衡的"第十七号状态"
3. 调整配色：
   - 祁叙的灰白透明 → 黎衡的琥珀暖色

**沈亦寒**：
1. 复制陆予觉的 cen-sub-panel 完整代码
2. 替换内容：
   - 陆予觉的"工作日程" → 沈亦寒的"案件进度"
   - 陆予觉的"社交动态" → 沈亦寒的"旧账档案"
3. 调整配色：
   - 陆予觉的风格 → 沈亦寒的冷峻灰蓝

**优点**：
- ✅ 立即可用
- ✅ 已验证稳定
- ✅ 用户熟悉交互

**缺点**：
- ⚠️ 可能被认为"照抄"
- ⚠️ 不够独特

---

#### 方案 2：参考结构，重新设计（推荐）

**学习 Mufy 的**：
- HTML 结构（浮球 + 面板 / 灵动岛 + 展开）
- JavaScript 交互逻辑
- 动画过渡效果

**自己设计的**：
- 视觉风格（配色、字体、装饰）
- 内容模块（人物专属信息）
- 图标符号（不用祁叙的颜文字）

**黎衡示例**：
```html
<!-- 学习 top-adaptive-dock 的结构 -->
<div class="lh-aroma-dock">
    <div class="aroma-island">
        <!-- 收起状态：显示"返照"标识 -->
        <div class="island-mini">返照</div>
        
        <!-- 展开状态：黎衡专属内容 -->
        <div class="island-expanded">
            <div class="aroma-status">
                <span>第十七号</span>
                <span>封存完好</span>
            </div>
            <div class="relation-gauge">
                <span>关系温度</span>
                <div class="gauge-bar"></div>
            </div>
            <div class="memory-tags">
                <span>烟草 + 青苔</span>
                <span>四个月前</span>
            </div>
        </div>
    </div>
</div>
```

**优点**：
- ✅ 保留了成熟的交互逻辑
- ✅ 视觉上完全独立
- ✅ 不会被认为"照抄"

**缺点**：
- ⏳ 需要 2-4 小时设计时间
