## 二、Lumeow 机制拆解（它到底在做什么）

1. **双层结构**：月卡（权益 + 启动币 + 每日滴币）+ 喵币直购包（消耗品，主利润）。
2. **月卡故意抠**：Lumini ¥29.9 只送 300 启动币（≈75 条 opus / 150 条 gpt），聊几天就见底 → 逼你充直购包。**月卡是权益 + 引流，直购包才是钱袋子。**
3. **按模型分级扣费** → 成本透传，避免重度/长上下文用户吸干毛利。角色扮演天然长上下文，此设计必要。
4. **每日滴币** = 留存钩子（每天回来领）。
5. **限时赠 X** = 大包锚定 / 紧迫感。
6. **隐含毛利**（估算）：sonnet 大包 ≈¥0.09/条，单条 output ~500tok COGS ≈¥0.05 → ~40% 毛利；零售 ¥0.18 → ~70%。daily 赠币是 loss-leader，靠零售鲸鱼补。

### 🚨 致命缺口

**Dearm 没有对外购币入口。** `/shop` 的「直购」tab 是 v1 占位（`src/app/shop/page.tsx`），`rechargeGoldAction` 仅 admin 可调（`src/lib/admin/recharge.ts`），silver 明确「暂不开充值口」。

→ 用户只能：买月卡拿 silver + 每日签到。**重度用户想多聊没处花钱** = Lumeow 的主利润池（直购包鲸鱼）在 Dearm 整个漏掉。**这是当前比调价更该补的洞。**

## 四、Dearm 定价策略建议

### 结论排序
1. **先建对外购币口**（补漏，比调价重要）。
2. 再按真实 COGS 校准币价。
3. 最后打磨月卡对比页文案。

### 1. 月卡：不改数字，改帐面观感
HK$30/68/128 已全线压 Lumeow。支付宝/微信结算给用户看到 HK$30≈¥27.6，天然「比 Lumini ¥29.9 便宜」。三档比 Lumeow 的 ¥29.9→¥188 断崖更好（68 是天然诱饵）。

| Dearm | ≈RMB | 对标 | 打法 |
|---|---|---|---|
| HK$30 黄金 | 27.6 | Lumini ¥29.9 | 头对头页面**每行权益肉眼多于 Lumini**（无限存档/面具 vs Lumeow 计数限制 x3/x360） |
| HK$68 铂金 | 62.6 | — | 填 Lumeow 断层，主推档 |
| HK$128 钻石 | 117.8 | Lumax ¥188 | 文案「Lumax 级权益，六折价」 |

### 2. 建公开购币阶梯（最高优先级）
`/shop` 直购 tab 做成公开 gold 充值（走 Stripe 买断，同月卡链路）。入门包比 Lumeow 更低门槛，大包咬住 ¥0.03/币。

### 3. 唯一要赢的数字：默认模型每条消息成本
用户不算大包单价，只感受「¥30 能聊多少条 / 常用模型贵不贵」。**补贴工作马模型**（sonnet/gemini-flash，压低 `goldCostPerCall`），在 opus/gemini-pro/出图收毛利。

### 4. Lumeow 抄不动的护城河型权益
- **创作者友好**：卡被聊→创作者分成/返币；AI 辅助生成送额度 → 供给侧变便宜 → 内容飞轮。
- **零审核/不限速**：写进卖点。
- **AI 辅助 + 调试**：边际成本极低、Lumeow 没有 → 月卡塞「每月 N 次 AI 生成额度」当差异化钩子。

### 5. 买断制留存补丁
每日滴币仅卡有效期内可领；「到期 X 天内回购保留连签奖励」；连续开卡小额忠诚返币。
