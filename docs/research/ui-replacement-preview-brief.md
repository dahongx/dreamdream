# 整站界面替换：预览阶段约束

## 2026-11-03 用户纠偏

用户认为早期桌面网页概念候选比后续手机原型更好看、区分度更高。后续应以 `outputs/ui-candidates/original-concepts/` 的三张原图作为视觉对照，保留桌面完整布局及各方案结构差异，再做手机适配。后来的 `boards.html` 不能代替原概念成为默认设计源头。用户尚未选定 B；“B 为基础结合 C 阅读”只是助手建议。示例不可使用测试角色沈亦寒。

更新：2026-10-23。用户明确要求整体替换升级，当前阶段先调研与提供多个候选预览，尚未选定实施方向。

## 已确认要求

- 基础网站整体升级；保留角色聊天、探索、创作等现有功能。
- 面向角色扮演、情感陪伴用户，重视吸引力、情绪、故事与沉浸。
- 可参考 Mufy 的体验，但需要与当前寄情的视觉和布局形成明显区别。
- 区别应覆盖导航、字体、信息层级、角色卡、聊天和控件，不能仅更换配色。
- 手机优先；模型列表此前被多次反馈过宽、过长，必须专门验收。
- 模型状态、响应时间和成功率要紧凑呈现；无样本时不能误报“流畅”。
- 聊天必须考虑中文长段落和角色自定义美化，不能只用短气泡证明可读性。
- 当前预览不等于发布授权；选定方向后先在测试环境验证。
- 保持现有角色美化 selector 契约，平台皮肤不得破坏角色自定义内容。

## 首轮反思

第一版“午夜影院”只用于概念讨论，用户未确认。横幅偏大，人物插画主导设计，聊天仅演示短句，未充分展示真实信息密度。后续候选应展示搜索筛选、最近对话、更多角色及长篇阅读。

## 本轮候选

1. 午夜影院：炭黑与莓红，横向导航，剧情海报与紧凑精选区，强调故事入口。
2. 心动频道：石墨灰与珊瑚色，搜索与主题筛选优先，人物卡片与最近对话并列，强调发现效率。
3. 私语档案：暖墨灰与灰绿，索引式侧栏与图文并列角色列表，阅读页采用稳定底色，强调长篇阅读。

候选图为生成式视觉概念，人物与指标是示意，不能视作线上数据或可运行的响应式验收。
