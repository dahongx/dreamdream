# 迁移台词装饰留白

产品理由见[适配说明](../insights/mufy-speech-decoration-space.md)。

2026-10-29，蛇谷凛在 390×844 视口实测聊天容器 clientWidth=375、scrollWidth=378。原因不是长日文不换行：作者的气泡 `::before` 装饰定位 `right:-20px`，迁移头像行占用了左侧 52px 后没有为右侧装饰预留空间。

`adaptMufySpeechDecorationCss` 是仅离线运行的 CSS 解析器（PostCSS），只识别公开来源气泡 before/after 的 absolute / 负像素 right，取有界最大值，在迁移头像行预留对应 padding-right。不裁剪装饰、不覆盖颜色、不隐藏滚动条，不进入普通角色的运行路径。相对单位、动态表达式、过大边距要求人工复核；已生成保护规则可去重，并随作者边距更新或消失而更新/移除。

准备器仅在公开 DOM 明确有台词头像时调用；未知来源不会自动加头像或空白。已补 5 项 / 21 断言；包含此改动的集中回归 205 项 / 878 断言及目标类型检查通过。

蛇谷凛通过正常主题编辑 UI 仅追加 119 字符，原 11,417 字符全部保留。重载主题逐字核对，通过新载入聊天页检查：10 行台词均有 20px 留白，原装饰 right=-20px 保留，聊天容器 clientWidth=scrollWidth=375。证据在本批 `final-acceptance/33/speech-decoration-owner-ui-repair.json`，不是整批验收完成或镜像发布证明。

另一个不同原因的个案是贺璟昫音乐：源码固定定位控件依赖 100px 画布，测试端被自动测为 1px。正常开场 UI 仅追加 97 字符恢复单个画布，保留原 120,859 字符；新页 100px、手机图标完整、真实播放/暂停及七页签正文核对通过。没有把它改成全局最小高度。
