## 分工与验收

协调者建立名单、运行版本指纹及唯一分配。执行者独占领取本地档案，正常浏览器观察公开来源、准备 XML、正常网页导入一次、记录实际目标 URL，再按 19 项契约逐项验收。每卡需两条不同的真实回复、手机及桌面视觉、公开组件清单与交互证据。

自修职责由 Codex 执行：保存失败证据，定位采集/转换/渲染/输出/外部资源原因，最小修复并实际复验。CLI 仅提供一个已证明的播放器盒模型修复配方及证据门禁；不代替真实语义和视觉判断。共享渲染器由协调者统一修改和发布，个人执行者不能并发部署。
