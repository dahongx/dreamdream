# Halo Ball v4.2 工具箱适配（未完成、未发布）

产品说明：[隔离适配的边界](../insights/mufy-halo-toolkit.md)。

林叙公开来源的独立工具箱依赖把模板注入父页面。2026-10-31 正常 Chrome 页面确认来源有约 38px 悬浮球和 268×500 面板；8091 对应模板所在 iframe 只有 1px 高，内部无实例化按钮。不能把该 iframe 里存在源码当作功能通过。

`stage-mufy-linxu-toolkit.ts` 仅解析已保存公开 srcdoc 的模板与 TypeScript AST 字面量，不执行脚本，不读取源站存储。保留 24 首原始曲目（同主机 HTTP→HTTPS）、17 个表情 URL、22 条默认指令。首曲原本就是 `#/song?...mp3` 页面链接，不能擅自当直接音频修正或称为可播放。

`MufyHaloToolkit.tsx` 已接入显式开场 envelope、ChatRoom 唯一工具箱和 consolidated runtime.patch，但尚未发布或在 TEST 验收。使用 Shadow DOM 和 DOMPurify，删除作者脚本、事件属性、iframe；有限动作以原生控制器重实现。歌曲、图片只在浏览器按原 URL 加载；文件导入仅本地 object URL，卸载撤销；没有发送或上下文 API。默认音频不预加载，播放状态以实际媒体事件及 Promise 为准。

已实现基础展开/关闭、遮罩/Escape、24 曲歌单、播放/暂停/切换/循环/进度、17 表情草稿复制、22 默认指令草稿复制/分组折叠、仅聊天容器的上下滚动、受限本地音频/头像选择。基础单测和定向类型检查不等于所有这些功能已浏览器验收。默认指令文案目前保持公开原文，用户/角色占位替换尚需结合正式宿主。

2026-10-31 后续已实现并局部验证：指令分组/增删/撤销、自己的隔离偏好存储、静默/前缀/后缀/注入模式；3 个手动发送入口共享作用域检查，工具箱本身仍无发送权限。本地无发送页面验证了精确前后缀拼接，刷新恢复、自定义文本保真与清理。老板模式五分类沿用原始 HTTPS 目的地，实际打开 GitHub；仅用户点击才导航，使用 noreferrer/noopener 和 no-referrer。分类与循环按钮的无障碍名称曾滞后，已补同步和回归检查。

涂鸦采用本地矢量笔画与有界离屏底图，保留 30 次撤销/重做，不读取外部图片像素；退出释放画布。截图像素验证了笔画、擦除、撤销/重做、清空/撤销。实际 390×844 CSS 视口发现工具条拖出下缘，已修指针释放后和尺寸变化时重新夹紧；合成多点触摸取消后下一笔可用。此证据来自 Edge 扩展 ID 4 和合成输入，不是物理手机。
