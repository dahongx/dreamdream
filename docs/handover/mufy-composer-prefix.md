# 迁移固定前缀配置面板

产品说明：[固定指令的安全迁移和会话隔离](../insights/mufy-composer-prefix.md)。

宋锦琛与江之余的公开美化均有固定指令面板，原 TEST 缺少入口。候选使用原 CSS、默认预设、原字体资源及实测继承颜色，配置 UI 由平台原生组件实现，不运行来源脚本，不读取来源站 localStorage、旧草稿或登录信息。

`mufy-public-prefix-extractor.ts` 只在 CLI 中使用 TypeScript AST 和惰性 HTML 解析，提取已知静态模板中的字面量 CSS、预设及 HTTPS 字体 URL。未知动态表达式拒绝提取。原畸形重复 border 声明被移除，其他样式保留。字体别名含资源 URL 哈希，避免作者更换字体后复用旧缓存。该解析器和 TypeScript 包不进入前端运行包。

`composer-prefix.ts` 定义显式惰性信封。开场路由不把它当普通 iframe 再渲染，用户名插值也不修改 JSON。重复信封不激活。运行时数据有长度、ID 唯一性、模式和 HTTPS 字体边界校验。

`MufyPrefixPanel` 的触发器与面板分别在 ShadowRoot 中，面板宿主挂到 body，避免输入框 backdrop-filter 改变 fixed 坐标。复制原色、13px 条目字号和320×380布局，手机限制在视口内。原生状态直接控制隐藏，不依赖会被通用样式清洗器删掉的作者 display:none。点击外部或聚焦输入框不阻止首击；Escape 关闭；编辑时中文输入法确认不误保存或发送。

配置写入平台自有 `nj_mufy_prefix_<sessionId>_<specId>`，只含用户自己编辑的指令和勾选状态，不包含聊天草稿。每会话独立，默认不勾选，不搬运来源偏好。刷新保留本会话；切卡/切会话时发送边界同时检查 scope，不能在 React effect 切换间隙套用旧配置。

ChatRoom 的手动发送、灵感确认发送、Host API 发送共用 `applyScopedComposerPrefix`，保留原同步发送锁。只在真正提交处拼接一次，不修改编辑中的正文，不自动发送，不作用于重说已有消息。多选顺序和无分隔拼接保留来源逻辑。配置增改不经过模型或数据库。

删除可撤销，撤销只恢复该条，不回退后续编辑或模式。超限输入保持在编辑框并提示；恢复不会产生下次读取时不合法的配置。原生标签沿用公开组件文字，未改动全站翻译词典。

本地真实组件已检查新增/编辑回车不误发、前/后缀、删除撤销、刷新保存、切会话隔离、首击聚焦与390px布局。两种面板字体均实际加载，实测原色分别为 `rgb(249,250,251)` 与 `rgb(122,31,31)`；白色背景只属于江之余版本。证据在两卡 `final-acceptance/<rank>/prefix-local-ui-check.json`，最终样式证据绑定组件与纯函数文件哈希，早期定位/预览溢出记录保留。

候选位于 `rule-repairs/<rank>/composer-prefix`；38候选包含其 Zen 浮窗候选。写 TEST 前必须正常 owner UI 重读当前美化并核对基线，不可覆盖之后的修复。当前未写 TEST、未构建/发布，实际网站发送链路须待整批发布门槛满足后复验。江之余音乐浮窗仍是独立待修项，不以此前缀修复代替。
