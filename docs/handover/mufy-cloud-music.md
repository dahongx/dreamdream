产品取舍见 [insights](../insights/mufy-cloud-music.md)。本功能仍为本地候选，未构建、未部署、未写入测试服角色。

## 输入与隔离

江之余公开来源组件的两首曲目、惰性标记与 CSS 由 CLI 静态提取。解析 TypeScript 字面量，不执行作者程序，不读取来源存储。`cloud-music` 仅允许严格验证的配置和 HTTPS 媒体；禁止携带作者 iframe 文档。前端由 `MufyCloudMusic` 原生控制，ShadowRoot 隔离样式，无作者 JS。

保留来源 310px 面板、53px 移动端触发器、继承 1.8 行高及色调。box-sizing 重置是适配，不改变来源配色。滚动按钮仅操作现有 `nj_chat_messages`。自动播放偏好只存本平台角色范围内的布尔值，不保存聊天正文或凭据。

## 生命周期与异常

父组件流式重绘不得替换音频节点、归零进度或重置开关。收起浮窗不停止播放；关闭自动播放暂停当前/待加载请求。加载中可以取消；异步播放承诺通过请求序号失效，卸载释放媒体。系统暂停后一次点击恢复。被浏览器阻止与媒体不可用分别记录，不把待加载当播放成功。
