# SFW演绎室重复与三卡针对性改编

产品思考见 [insights](../insights/sfw-reel-duplicate-and-faithful-v2.md)。本记录取代旧三卡交接中“未完成浏览器验收”的当前状态；旧记录保留作历史。

## 根因

8094的`opening_components`是独立的数据源。每个保留的美化包都有两条组件，分别含有同一套完整人物介绍和播放器，两个均enabled。只改characters字段不会更新这些组件。浏览器复现两套人物介绍、两套悬浮播放器和旧成人文字后，读取数据库确认六条组件。

不是通过前端文本去重或全站隐藏第二组件修复，避免误伤其他卡本来合法的多组件组合。本次只修SFW样站的三个特定角色数据。

## 修复范围

数据源仅`supabase-db`中的`dearm_sfw`，不对`postgres`或`dearm-prod-db`写入。原四张相关卡的人设和开场指纹再次复核一致。
