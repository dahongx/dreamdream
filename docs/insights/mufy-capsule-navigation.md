# 查找可以保留，整页权限不必迁移

技术交接见 [handover](../handover/mufy-capsule-navigation.md)。

用户需要的是熟悉的细胶囊、查找面板和消息跳转，不是原站的父页面注入机制。限定在聊天容器中搜索可复现这些意图，也避免误滚页头或把其他弹窗、作者资料甚至隐藏应用状态算进结果。不透明组件内部内容不跨边界读取，需要明确保留这种范围限制。

“复制了按钮CSS”还不够：来源依赖全站预设的零内边距和SVG块布局。在隔离组件里若漏掉这些继承契约，14px箭头会被压到8px，面板高度也会变。验收要对照真实几何、回车/失焦提交、拖动边界和连续查找，不能只看壳出现。

拖动和高亮都是临时界面状态，应在关闭、卸载时清理，不写进角色设定或用户草稿。数字超界和无结果由控件明确处理，而不是替换用户输入或依赖定时器恢复。
