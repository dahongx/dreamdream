# 适配应给原装饰留空间，而不是删掉装饰

技术边界见[交接说明](../handover/mufy-speech-decoration-space.md)。

角色气泡的角标、画像和外溢描边都属于作者的视觉语言。复制了样式，未必复制了可用空间：寄情在内容流内安置台词头像后，气泡右侧仍可能带来源的负 inset，从而只溢出几个像素，却让整条聊天流出现横向滚动。

处理原则是保留原装饰，并依据明确的来源数值为它留位；不能用 overflow:hidden 掩盖，也不对所有角色统一缩窄。没有对应装饰的卡保持不变。未知尺寸不猜，过宽或动态计算的布局单列复核。

同理，固定在来源小画布中心的音乐入口不应被一像素自动高度吞掉。它需要恢复已测量的画布语义，而不是给整个站点加最小高度。小问题必须由真实尺寸、控件操作和重新载入后的画面来证明解决，不能只查 CSS 字符串。
