# 面具交互设计

## 最新落地边界

「无面具」也是确定的身份选择，统一使用「确认选择」，无需额外停用按钮。新版不改变付费权益：普通和黄金限2张，钻石/铂金有效期内不限；无面具不占名额，到期也不收回已有面具的使用、编辑权限。前端限制新增入口，后端负责不可绕过的额度验证及并发保护。管理员界面体验与普通/会员额度验收分开；当前25项自动化测试通过，真实测试服账号验收尚待部署，不能用本地预览代替。

## 第三版：选择优先，编辑分层

用户认为前两版仍过于复杂，第三版不再在同一界面同时呈现选择与六字段表单。面具弹窗首先是快捷切换器，其次才是资料编辑器。统一单列卡片：名字、铅笔、星标；只有正在使用的一张附带「使用中」。取消重复当前对话横条及默认成功文案。

所有卡片点击只选中，包括不使用选项；底部唯一CTA明确执行使用/停用。铅笔打开编辑页，「更多设置」收起次要字段，保存仅保存并返回列表。默认星标与当前聊天绑定继续独立。整体沿用夜青银风格，以删减信息与分层操作改善体验，不添加装饰。

技术交接：[实现与验证](../handover/mask-dialog-interaction.md)。

用户明确要求保留星标默认，且默认与当前使用互不干扰。问题不在星标，而是点资料即切换身份，与保存并使用混淆。

本轮将浏览编辑与启用分开，顶部只报告当前聊天的真实绑定。默认星标保持一键设置，不新增多余确认弹窗；「不使用面具」也有同款星标，表示新会话默认不用面具（存储仍是所有真实面具的默认标志为false）。编辑同一面具会影响多个聊天的后续回复，保存按钮title说明范围。

用户反馈常驻说明过多，第二版移除长段帮助和卡片旁解释；所有身份选项共用同款卡片，星标和使用状态分开呈现。手机横向列表保持边缘露出提示可滑动，44px星标触控范围不缩小。

美化遵循既有夜青银配色与字体，不改聊天工具栏或角色皮肤。移动端用横向身份列表减少纵向占用，扩大按钮触控，优先展示姓名和身份设定。保留草稿避免切换查看时丢失输入。
