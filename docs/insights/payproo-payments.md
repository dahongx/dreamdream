# 产品思考：PayProo 支付

> 技术交接见 [handover/payproo-payments.md](../handover/payproo-payments.md)。

PayProo 适合补足 Dearm 现有 Stripe 链路在本地化支付场景的覆盖。香港业务覆盖
微信支付、AlipayHK 与八达通 HKD 收款；台湾测试业务先接入 TWD 信用卡收款。
现有月卡仍然是 30 天一次性买断，不引入自动续费。

本次保留 Stripe 与 PayProo 双通道，并通过服务端环境变量切换，原因是：

- PayProo 测试与生产账号、密钥、IP 白名单完全分离，需要保留 Stripe 作为已验证的
  回退通道。
- 两个渠道都使用同一张 `payment_orders` 和同一套会员/金币履约核心，减少渠道差异
  对账与用户权益的影响。
- 前端回跳只做状态展示，异步通知才是收款事实，避免用户跳回页面时提前发货。

运营上需要特别注意 PayProo 后台的业务币种、支付方式开通状态和服务器出口 IP；
代码本身成功创建订单不代表已经收款，生产验收必须以签名通过的异步通知和订单查询
结果为准。
