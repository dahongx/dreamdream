# 不只验证空草稿和展开状态

2026-11-03。实现与证据见 [技术交接](../handover/mufy-ins-sidebar-fidelity-20261103.md)。

“能展开、文字一样”没有覆盖按钮在有内容时的真实行为。祁述的单个指令正确，连续点击却多一处换行；本地预览此前直接替换草稿，所以无法代表聊天页。验收环境必须复用生产草稿处理逻辑，并测试连续操作与重绘。

同一个白色侧栏的颜色看起来一致，也会受宿主页的按钮默认字体和行高影响。移入独立iframe后，应恢复原来的宿主默认值，同时保留作者显式覆盖。固定205px不能随意改成20vh；来源已有间距不能再叠加一次。

图片需区分懒加载和损坏。本轮正常滚动后60张都解码一致，期间的15、39、51、56张是过程观察，不是资源失效。媒体播放、图片、指令内容、连续拼接和定位分别留证，不能互相代替。

修复有明确的线上／本地边界：三个页签、60张图片、20个独立指令已在TEST实测；几何、字体与连续拼接只在本地新代码通过，等整批准备完成后统一受控发布，再做真实TEST复验。
