# 文字润色不是角色重写

技术记录见[handover](../handover/sfw-text-only-v3.md)。

用户要的是保持原卡特色，只改敏感部分；前两轮把人物、关系和剧情改写过多，又改了音乐、指南和布局结构。即使新稿可读，也不符合需求。

当前以原始卡片为唯一基线：江淮保留挑衅俏皮的短句，程不疑保留敬语与心声反差，谢寻保留骗婚、旧情和反噬的叙事钩子。非露骨的嫉妒、欺骗、婚姻和坏蛋玩家属于虚构戏剧，不因去除成人文字而全部抹平。

敏感改动限制到具体句子、原文明确的成人指令块与HTML文本节点。图片、样式、音乐、控件、注释和脚本以原始字节比对；这比凭印象说“保留原风格”更可核查。去重是既有缺陷修复，不以此为由再简化或重新设计其余模块。
