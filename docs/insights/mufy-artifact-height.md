# Content completeness includes the outer frame

Seeing complete text in a public DOM snapshot does not prove that a reader can see it. Rank28 exposed a complete347px narrative behind a240px host frame. Acceptance must compare inner content size with the actual outer viewport, then exercise fold growth and shrinkage.

Use a bounded parent/child measurement handshake rather than raising a fixed minimum or weakening the sandbox. A fixed large height would hide this failure but leave collapsed panels with blank space. Browser checks of20→620→20px verify both directions. Local success remains distinct from integrated TEST acceptance and visual typography parity.

See [implementation handover](../handover/mufy-artifact-height.md).

Public platform defaults also matter when author CSS relies on inheritance. Preserve the observed source defaults only for imported documents, at a lower priority than authored styles. A three-way browser fixture checks imported inheritance, ordinary platform behavior, and explicit author overrides together; this guards against fixing one imported card by recoloring every artifact.
