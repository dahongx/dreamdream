# 三张普通剧情样卡的改编原则

技术交接见 [handover](../handover/sfw-three-card-review-20261109.md)。

目标是让普通内容版真实提供独立的故事体验，保留人物差异，同时移除不适合公开展示的成人设定与开场；不把标签改名当作内容改写，不用临时页面掩饰实际业务。

江淮保留理性、克制与自我选择的矛盾，故事入口变成雨夜认错人和旧城书店线索。程不疑保留冷幽默、职业能力和下班边界，奇幻机制只响应玩家主动提供的心声，删除窥私机制。谢寻采用26岁成年版，保留外冷内细和旧友重逢，删除欺骗与控制关系，将往事线索放在庭院与照片中。

三张卡都允许玩家拒绝合作、安静停留或离开，避免把“温柔”写成强制安排。长设定重整为清晰的背景、性格、关系起点、长期线索和对白示例。头像封面保留，减少无关的界面改造。

配套通用prompt必须与站点内容定位一致，不能一边改成普通卡片，一边仍要求模型主动创作成人内容。此次保留原站完整版本，在独立新库试做；新库清理前完整备份，不删除共用图片。

九次模型检查提供初步证据，不能替代全部模型、输入和第三方支付审核。先给老师查看真实的三卡样站与改写对比，再根据反馈扩大内容数量。
