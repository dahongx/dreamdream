# 指令面板不能只复制外壳

技术交接见 [handover](../handover/mufy-command-drawer.md)。

来源组件将可复用指令注入父页面；直接塞入聊天正文 iframe 会丢固定位置，复制作者父页面代码又扩大权限。适配应提取明确的公开默认数据，用原生控件实现有限能力：填草稿、维护本地自定义条目，不附带发送、上下文或来源存储访问。

本轮发现的三个视觉陷阱：安全样式清理会移除 fixed/pointer-events；作用域转换后根变量可能落不到后代；通用按钮重置会覆盖作者标题类，导致白底浅字。验收应看实际截图及稳定后的计算样式，不能仅按按钮存在或点击返回成功判通过。

来源下载未完成、来源本身不能播放、浏览器渲染中间帧必须分开记录。局部修复通过也不能替代整卡验收，更不能提前构建发布。
