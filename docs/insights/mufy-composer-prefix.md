# 固定指令的安全迁移和会话隔离

技术交接：[迁移固定前缀配置面板](../handover/mufy-composer-prefix.md)。

迁移需要保留的是作者给玩家的可用工具，不是来源站拦截键盘、读取草稿和注入父页的实现方式。面板外观沿用各卡的公开样式，配置和发送由平台自己管理：默认不启用，用户勾选后只在手动发送时生效。

会话之间不共享指令或勾选状态。原站按浏览器共享偏好容易使另一张卡继承旧指令，目标按会话隔离，刷新仍保留。用户能看到、能编辑、能取消选择，原正文不被组件悄悄改写。

“自查自修”不应只测按钮能点。要覆盖保存后刷新、切卡瞬间、中文输入法、撤销后的后续编辑，以及原色和字体是否被平台默认样式覆盖。删除可恢复，输入超限不丢文本；回归失败先保留真实记录，补验成功也不抹去原异常。

本地组件通过不等于整批验收。候选与测试服已保存版本必须明确分开，发布前复核当前基线，避免旧候选覆盖已修好的内容。
