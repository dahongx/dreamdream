# 8093 个人中心产品思考

日期：2026-11-10。实现及验收状态见[技术交接](../handover/reskin-8093-personal-center.md)。

## 让主页承担导航

个人中心主页集中九个入口，把邀请、钱包、收益移入带返回入口的独立子视图。这样用户先选择任务，再查看具体内容；主页无需同时承载多组明细和空态。子视图仅接受三个白名单 section，保持清晰、有限的导航结构。

角色管理保留一个方向：`/mine` 跳转到 `/create?tab=characters`，与已有创作页衔接，避免在个人中心再建立一套角色管理界面。可选的初始 tab 和隐藏导航参数仅服务当前入口，其他 `ProfileTabs` 用法维持默认体验。

## 以真实状态验证入口

真实 8093 验收覆盖九入口、钱包与收益空态、邀请复制及三条记录展开、关注空态、设置、商店、近期会话与收藏空态。桌面 1440px 使用三列入口；手机 390px 和 360px 下，探索及创作页的大图分别约为 177×319px、162×292px，已检页面没有横向溢出。

这些结果说明当前导航和内容状态可用，但不代表真实支付、模型生成或手机实机触摸已验收。网络链路间歇 reset 时通过临时 SSH 隧道访问真实站点，并非替代数据或 mock；不据此推断网络问题已永久解决。

## 从 QA 中删除无效信息

邀请子视图重复标题会让内容层级显得冗余，通过 `ReferralSection` 的可选 `hideTitle` 保留一个清晰标题。收藏页空白筛选条既存在字典缺失，又指向尚为占位的收藏夹功能；本次移除无效占位条，保留已有搜索和收藏能力，不让用户面对没有实际用途的控件。

以上两项 QA 修正已构建并发布到8093，部署后确认邀请标题唯一、收藏空态没有空白按钮，钱包和收益入口未回归。最终镜像为 `edabddc57c15...`，详细日志和截图位置见技术交接。本轮仅限 8093 测试站，未改正式服。
