# 连点和清空重试应是迁移验收必测项

技术交接见 [handover](../handover/mufy-draft-relay.md)。

“按钮能把字填进输入框”只覆盖第一次成功，无法证明追加语义正确。桥接层必须明确传递的是增量还是完整草稿；混用会把用户删掉的旧文字带回来，甚至越点越多。本轮通过连续点击与清空后重试定位了公共桥接根因，优先修平台专用 relay，避免逐卡修改作者程序。

快照不是可直接重放的程序状态：DOM 上的 initialized 标记保留，事件监听器却不会序列化。迁移 agent 应在明确的组件签名下重置初始化标记，并以真实组件交互复验，不能泛删所有 initialized 类。

发布检查也应覆盖集成依赖与精确候选类型检查，而不仅是文件哈希相等。保留其他任务已上线的模型刷新通知，避免修迁移组件时带回无关版本差异。局部回归和候选验证不等于整批上线验收。
