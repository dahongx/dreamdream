# 独立侧栏不是普通内容块

技术记录：[INS 三标签侧栏](../handover/mufy-ins-music-sidebar.md)。

有些来源原件把菜单固定在整个页面，而非正文中。把 template 或注入桥原封不动塞入普通内容 iframe，会留下原始代码却没有实际入口。验收要看页面上能否打开、能否切换、复制是否只填草稿、回复后是否保持单实例。

兼容分两层：无脚本宿主外壳负责原位置和开合；隔离程序负责原作者的列表、媒体与交互。迁移不能以访问真实父页面换取方便，也不能自行发明发送行为。

资源与交互分别记账。第二首能真实播放不代表第一首或所有外链图都通过；某幅原图失败也不意味着应重新设计作者整套风格。
