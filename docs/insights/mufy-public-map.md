# Matching the image does not match the interaction

The rank49 map looked identical on both sites but silently lost its header notifications because an opaque iframe cannot insert into the host document. Accepting its text and SVG alone would have shipped a broken control.

The repair preserves the author's map and finite public notification text without opening a general parent-DOM API. Native timers handle replacement, completion and reply repaint; the author's code stays inside its original evidence rather than executing in the host. No message is sent and no credit is consumed by clicking the map.

The UI hardening review influenced queue replacement/cleanup, keyboard activation, viewport-clamped notification placement and separation of delayed paint from real failures. Raw source strings remain original content rather than platform translations. Release is still gated on actual TEST integration after whole-batch preflight.

# Source boundaries versus media loading

Rank48 exposed a second distinction: a button labelled COPY is not permission to turn its public text into a chat draft. Real clipboard contents and confirmation feedback must both be checked. A copied payload with a failed badge led past the initial timing hypothesis to an unnecessary parent Proxy breaking receipt identity. Omitting only that self-contained hub's shim fixes the cause while retaining opaque isolation; widening sandbox access would not address it. Eight actual copies plus repaint/reopen are now checked locally. Original media availability remains separately qualified, including the cold initial URL and the second rank46 track; successful UI tests do not manufacture decoded playback or release approval.

The rank21 follow-up separated two independent issues. Extra internal native scrollbars came from the host overriding the source document's HTML clipping boundary; partial portraits progressed to full completion without replacing URLs. Fixing CSS must not be reported as restoring image delivery. The same source base CSS occurs beyond one author's templates, so card-name patches are not a scalable endpoint. The local shared solution recognizes that exact base CSS instead of role names, leaves body auto-height measurement intact and lets later author styles win. Actual four-component/five-fold/three-modal/author-override checks support the change; recognition across175 saved frames is not175-card UI acceptance. Arbitrary artifacts and parent/reply skins retain their prior reset. TEST integration remains separately gated.
