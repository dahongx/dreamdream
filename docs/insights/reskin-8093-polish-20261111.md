# 8093 润色思路 — 2026-11-11

保留用户指定的深色、手机宽版和双列大图。问题是各组件仍混有发光按钮、拥挤标签、重复品牌以及过高个人信息区。优先统一这些真实页面细节，避免通过更换主色或新增装饰掩盖问题。

人物图是视觉焦点，辅助信息使用安静、清晰的层级；手机标签只展示两个完整词，详情保留全部。个人中心缩短头部，让常用入口更早出现，统一图标和箭头明确可点击性。

动效承担操作反馈：短促颜色过渡、桌面图片轻微聚焦、弹层淡入淡出。没有给整页或所有卡片添加依次入场，也不会延迟路由跳转。减少动态效果偏好下关闭位移与弹层动画。
