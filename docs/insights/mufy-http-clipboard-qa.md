# Copy receipts are not copy acceptance

A successful acknowledgement and button label are insufficient when users need
the exact original command in their clipboard. This batch checks normal paste
as well as UI receipts, keeps external-resource and generation qualifications
separate, and does not substitute a local fixture for the actual deployed site.

However, a failed automation observation is not automatically a product bug.
Use a positive control and a direct, scoped browser check before shipping a
common clipboard change. Preserve failed observations and avoid another broad
release based only on a hypothesis. Source duplicate IDs are a separate fact,
not an excuse to rewrite the source silently.

See [handover and current blocker](../handover/mufy-http-clipboard-qa.md).
