# 润色应保留角色，而不是把所有故事改成同一种生活

技术交接见 [handover](../handover/sfw-reel-duplicate-and-faithful-v2.md)。

初稿把三个人都移到阅读会、庭院或社区项目，虽然移除了成人场景，却同时磨掉原卡的世家、秘书、青梅和关系误会。用户明确要求以原人物及形象为依据，因此第二版恢复这些差异，仅改动不合适的情节与边界。

江淮的戏剧性来自理智与一次清醒的主动选择；程不疑来自职业冷淡与心声暴露的反差；谢寻来自责任、家族安排和旧情误会。普通内容并不要求取消含蓄情感或一切冲突，而是让人物始终保有自主，把冲突通过沟通和选择推进。

另一项教训是验收对象必须覆盖实际呈现链路。人物表、作者说明、开场、演绎室组件、折叠内容和实际聊天是不同来源。第一次只检查角色字段与模型结果，漏掉独立组件，造成网站上两套旧人物介绍仍可见。第二版通过登录浏览器复现再修复，不用接口成功代替页面验收。

原版和本次样站的历史备份都保留，修改只在独立新库。先交付真实可玩的三张样卡，再依据用户对人物质感的反馈扩展数量；不以临时隐藏页面宣称支付机构已通过审核。
