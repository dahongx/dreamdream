# 保留角色设计，同时适配玩家与平台控件

2026-11-03。技术交接见 [实现与验证](../handover/mufy-player-identity-controls.md)。

玩家截图暴露两类适配问题：来源把默认玩家名称直接写在展示组件里；快捷按钮移植后与平台原生操作争用输入区。原样保留来源文本和坐标，不能满足可切换面具、多原生按钮的产品行为。

名称应绑定当前玩家／面具，作者署名不应跟着变；切换名字也不该重置用户展开的内容。因而用保留原节点的文本绑定，避免每换一次面具就重装 iframe。

快捷按钮继续使用来源形状、色彩和功能；排列顺序服从平台可用空间。宽屏同行，窄屏换行，避免为了照抄来源绝对坐标而盖住模型、币种或输入框。窄屏多一行是空间不足的明确适配结果，不能宣传成与来源截图逐像素一致。

本地真实组件证据与线上整卡证据分开记录：预览的四个原生按钮只是尺寸占位；上线后的模型选择、币种长文案、面具激活态、手机安全区仍需实际检验。修复已准备，不把待发布写成已修复。
