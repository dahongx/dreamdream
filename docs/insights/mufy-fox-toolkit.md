# Complete source inventory includes global tools

A matching intro and working profile folds did not prove that Chen Chuang's migration was complete. The source's player and tools were launched from a zero-area program in a second public root. The old root-0-only mapping missed that whole function family.

The repair keeps authored markup, colors, typography and public defaults while replacing broad parent-page execution with finite native actions. It preserves this author's draft replacement contract rather than imposing another card's append behavior. Local tests protect audio identity and state during parent redraws, which previously caused disappearing or reset widgets.

Browser checks caught differences invisible to the initial unit suite: the platform's inherited font metrics, clipped external tools, and an untouched floating ball retaining desktop coordinates on mobile. Those are now corrected against measured source behavior. Default positioning stays responsive; only deliberate dragging creates a persistent anchor. The author's quiet interval and single-bubble lifetime replace the prototype's overly frequent animation.

This remains an unreleased candidate. All ten native commands were exercised in Chrome; a real reload restored a locally created command, and the first original track decoded and progressed. Remaining media, actual uploaded-image/background integration, and TEST acceptance still need proof. A source click timeout and a later successful visible effect are both evidence; neither should erase the other. Human review remains the final audit after those checks.
